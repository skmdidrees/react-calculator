# React Calculator

A responsive calculator application developed using React and Vite. This project provides a simple and interactive interface for performing basic mathematical calculations.

## Features

- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Decimal number calculations
- Positive and negative number toggle (±)
- Percentage calculation (%)
- Backspace functionality
- Clear all functionality (AC)
- Division by zero error handling
- Responsive design for different screen sizes

## Technologies Used

- React – Building the user interface using reusable components
- JavaScript – Implementing calculator functionality and logic
- HTML – Structuring the application
- CSS – Styling and responsive layout
- Vite – Development server and build tool
- Git – Version control
- GitHub – Source code repository
- Vercel – Application deployment and hosting

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/skmdidrees/react-calculator.git
```

**2. Navigate to the project directory**

```bash
cd react-calculator
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in the terminal to access the application.

## Production Build

To create a production-ready build, run:

```bash
npm run build
```

## Deployment

The application is deployed using Vercel, with GitHub integrated for source code management and deployment updates.
